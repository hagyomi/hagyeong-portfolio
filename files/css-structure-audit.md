# 구조·CSS 검수 기록

검수일: 2026-11-05. 현재 소스 기준 기록입니다.

## 정리 내용

- 연결되지 않은 데모 HTML 5개와 전용 공통 파일을 제거했습니다. 현재 HTML은 메인과 이벤트 상세 3개, CSS는 10개입니다.
- 삭제된 전환·갤러리·CTA·챗봇과 예전 프로젝트 화면의 CSS 선택자 1,155개를 정리했습니다. 사용하지 않는 keyframes와 주석도 제거했습니다.
- 공통 JS의 미사용 애니메이션·이벤트 리스너·상태 변수와 도달할 수 없는 코드를 제거했습니다. 푸터 Canvas는 현재 사용하는 정적 장식으로 단순화했습니다.
- 숨김 복제 요소와 사용하지 않는 목업 곡선을 제거했습니다. 구조 선택자가 달라지면서 생긴 모바일 여백 차이를 수정했습니다.
- 빌드에 참조 추적 검사를 추가했습니다. 현재 배포 파일 118개가 메인 페이지와 연결되며, 누락·미연결 파일과 알 수 없는 공통 토큰은 없습니다.
- 검수 문서와 제작 메타데이터는 배포 결과에서 제외합니다. 캡처 도구의 출력은 `.local-preview/`로 정리했습니다.

## 검수 결과

- `npm run build`: HTML 구조·CSS 자산·파일 참조·공통 토큰 검사 통과.
- 메인과 이벤트 상세 3개 × 390·768·1024·1440px: 페이지 검사 16건 통과.
- 주요 구간 56건, 영상 재생 20건, 내부 링크 48건 통과.
- 모바일 메뉴 열기·Escape 닫기, 전체 Q&A 펼침·닫힘, 내비게이션, 모션 감소 설정 통과.
- AI 영상 미리보기에서 해당 영상으로 이동·제목 포커스·재생 6건 통과.
- Skill 캐러셀 13개 카드의 휠·키보드 조작, 맨 위로 이동 통과.
- 이미지 누락·가로 넘침·중복 ID·끊어진 내부 앵커·JS 예외·HTTP 오류 없음.
- 네 가지 화면 크기의 정리 전후 스타일 차이 0개. 삭제 대상으로 확인한 숨김 요소 5개는 각 기준 화면에서 제외한 뒤 남아 있는 요소를 비교했습니다.
- 데스크톱·모바일의 주요 화면과 이벤트 상세 페이지 캡처를 확인했습니다.

## 재검수

로컬 서버 실행 후 아래 명령을 사용합니다.

```sh
npm run build
node tools/full-page-check.mjs
node tools/full-page-check.mjs --interactions-only
```

전체 결과는 `.local-preview/full-page-report.json`, 추가 조작 결과는 `.local-preview/interaction-report.json`, 캡처는 `.local-preview/full-*.png`입니다. 스타일 비교 도구는 `tools/css-structure-check.mjs`입니다.

삭제 목록과 정리 합계는 `files/cleanup-audit.md`에 기록했습니다. 검수 환경은 로컬 Chrome이며, 외부 사이트의 내부 기능·실제 모바일 기기·Safari는 포함하지 않습니다.
